Hajime no Ippo Portable - Victorious Spirits (English)
English fan translation patch, version 1.0

This patch contains no game data. You need your own copy of the original Japanese game.

  Size:  547,053,568 bytes
  SHA-1: 8C83374FD829EB18480DF39932F96CA50432AC81

How to apply
  Delta Patcher (Windows/macOS/Linux): Original file = your Japanese ISO,
  XDelta patch = Hajime no Ippo Portable - Victorious Spirits (English) v1.0.xdelta, then "Apply patch". It writes the English ISO.
  xdelta3 (command line):
    xdelta3 -d -s "<Japanese ISO>" "Hajime no Ippo Portable - Victorious Spirits (English) v1.0.xdelta" "<English ISO>"
  Keep a copy of your original ISO; the patch only works on the unmodified file.

Play the patched ISO in PPSSPP or on a PSP (custom firmware, plain ISO loading).

What is translated
  Story mode (all 35 chapters), menus and help text, boxer and move names, the boxer roster,
  menu and title graphics, arena scoreboards and banners.
