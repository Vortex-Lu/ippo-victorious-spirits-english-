Hajime no Ippo Portable - Victorious Spirits (English)
English fan translation patch, version 1.0.1

This patch contains no game data. You need your own copy of the original Japanese game.

Original ISO (the patch only applies to this exact file):

  SHA-1: 6DF763C67265B65CABE00AD7CC396AA5109CB03D

Patched ISO after applying:
  Size:  547,053,568 bytes
  SHA-1: 0E2D7B259E3C796BCF784CDFFC226717B211FE1A

How to apply (Delta Patcher, Windows/macOS/Linux)
  1. Make a copy of your Japanese ISO. Delta Patcher changes the file you pick,
     so patch the copy and keep the original safe.
  2. Open Delta Patcher.
  3. "Original file": click the folder icon and choose the COPY of the ISO.
  4. "XDelta patch": click the folder icon and choose
     Hajime no Ippo Portable - Victorious Spirits (English) v1.0.1.xdelta
  5. Click "Apply patch" and wait for the success message (a few seconds).
  6. The copy is now the English game. Rename it if you like, e.g.
     "Hajime no Ippo - Victorious Spirits (English).iso".
  If it reports an error, your ISO is a different dump: compare its SHA-1 with the one above.

How to apply (xdelta3, command line)
    xdelta3 -d -s "<Japanese ISO>" "Hajime no Ippo Portable - Victorious Spirits (English) v1.0.1.xdelta" "<English ISO>"
  This writes a new English ISO and leaves the Japanese one untouched.

Play the patched ISO in PPSSPP or on a PSP (custom firmware, plain ISO loading).

What is translated
  Story mode (all 35 chapters), menus and help text, boxer and move names, the boxer roster,
  menu and title graphics, arena scoreboards and banners.
